りんごハンコ v15

【v5での修正】
■ v15での追加
・5個目以降のハンコを金りんご（assets/apple-stamp-gold.png）に変更しました。
  1〜4個目は赤りんご、5個目以降は金りんごです。
  番号はカード（旬）ごとに1から数え直します。

■ v14での追加
・リスナー用ページと操作画面でも、ハンコを押した瞬間に
  OBS通知と同じ押印演出が出るようになりました。
  りんごが約4倍の大きさで上から降ってきて、その日のマスに着地。
  着地に合わせて衝撃波が広がり、カードが「ドン」と沈み込みます。
  リスナー用は効果音も着地の瞬間に合わせて鳴ります（自分の端末のみ）。
  操作画面は無音のままです（OBSの音と二重に鳴らないようにするため）。
・演出は「今押したとき」だけ再生されます。
  ページを開き直したときは静かに表示されるだけです。

■ v13での変更
・リスナー用ページ（listener.html）を作り直しました。
  プルダウンでの選択をやめ、名前を入力するだけの流れにしました。

  【初回】
  1. お名前を入力（よみがなは任意）
  2. 「この名前で始める」→ 端末に記憶され、そのままハンコ画面へ
  3. 「出席ハンコを押す」

  【2回目以降】
  URLを開くと、いきなりハンコ画面が出ます。ボタンを押すだけです。

  ・同じ名前がすでにある場合は、新規作成せずその登録を引き継ぎます。
    「こまち」と「こ まち」のような空白の違いは同一とみなします。

  ・「名前を変更する」で登録し直せます。出席記録は消えません。
  ・プルダウンを廃止したことで、他のリスナーの名前が一覧で見えなくなりました。

■ v12での追加
・ハンコの効果音を追加しました（音声ファイル不要・ブラウザ内で合成）。
  「ドン」という着地音＋紙に当たる音＋きらりと上がる3音の組み合わせです。
  OBS通知：ハンコが着地する瞬間（表示から約1.25秒後）に鳴ります。
  リスナー用ページ：押した瞬間に鳴ります（自分の端末のみ・配信には乗りません）。
  操作画面（stamp.html）は無音です。OBSの音と二重に鳴るのを避けるためです。

  【OBSで音を出す設定】
  ブラウザソースのプロパティで「OBSで音声を制御する」にチェックを入れてください。
  音声ミキサーに項目が現れるので、そこで音量を調整できます。

  【音量・無音の切り替え】
  URLの末尾に付けて調整できます。
  ?sound=off        無音にする
  ?vol=0.4          音量を下げる（0〜1、初期値0.7）
  ?panel=on&vol=0.4 のように組み合わせも可能です

■ v11での変更

  カードと文字だけが浮いて見えます。文字には白フチを付けたので、

  従来の枠付きに戻したい場合は、OBSのURLの末尾に ?panel=on を付けてください。

■ v10での追加
・OBS通知にスタンプカードへの押印演出を追加
  その人のカード（旬に応じた台紙）が出て、すでに押してある分が並び、
  今回の1個が上から降ってきて着地します。着地に合わせて衝撃波とカードの揺れが入ります。
  文言は「上旬 5日 ハンコGET！（3個目）」のように旬・日付・累計を表示します。
  表示時間は約5秒。複数人が同時に押しても順番に流れます。
・管理画面に「出席漏れを後から追加」を追加
  リスナーと日付を選ぶだけで、過去の日付でも出席を追加できます。
  重複は自動でチェックします。追加分には「後から追加」バッジが付きます。
  追加してもOBS通知は流れません（配信中に過去分を入れても画面が荒れません）。
・管理画面の出席一覧に「旬・◯枚目」を表示

■ 仕様の変更
・日付の切り替えを23時に変更
  23:00～翌22:59が「1日」です。23時以降に押したハンコは翌日の出席になります。
  変更したい場合は common.js の DAY_ROLLOVER_HOUR を書き換えてください（0＝通常の日付）。
・ハンコの絵柄を1種類（りんごイラスト）に統一
  枚数による絵柄の変化（🍏／👑）は廃止しました。
  差し替えるときは assets/apple-stamp.png を同名で置き換えるだけです。
・リスナーが自分で名前を登録できるようになりました（管理画面での事前登録が不要）
  同名チェックつき。本人登録された名前は管理画面にバッジが出ます。
  firestore.rules を更新したので、必ず新しいルールを公開してください。
・カードの背景を手描きの木から、旬ごとのスタンプカード台紙イラストに変更
  上旬（1〜10日）・中旬（11〜20日）・下旬（21〜31日）で台紙が自動で切り替わります。
  ハンコは「押した日付のマス」に正確に入ります。順番でずれることはありません。

【画面】
index.html     入口
stamp.html     配信者が操作する出席ハンコ画面（PINなし・開いてすぐ使える）
listener.html  リスナーが当日のハンコを押す
admin.html     管理画面（PINなし）
obs.html       最新ハンコを約3秒表示
public.html    月別の出席回数を公表

【初回のリスナー操作】
1. listener.html を開く
2. お名前を入力（よみがなは任意）
3. 「この名前で始める」
4. 「出席ハンコを押す」

※同じ名前がすでにある場合は新規作成せず、その登録を引き継ぎます。
※管理画面で「停止中」にした名前は再登録できません。

【2回目以降】
URLを開き「出席ハンコを押す」だけです。
名前はlocalStorageに保存されます。
ブラウザのデータを削除した場合や、別端末では再登録が必要です。

【管理画面】
admin.htmlを開くとそのまま使えます（PINは廃止しました）。
代理登録、修正、停止、削除、出席取り消し、LFR履歴管理、通知履歴の整理ができます。
リスナー本人が登録した名前には「本人登録」バッジが付きます。
不適切な名前や重複はここから修正・停止・削除してください。
※代理登録するときは「よみがな」必須です。空だとリスナー画面の一覧に表示されません。

【OBS】
OBSブラウザソースにobs.htmlの公開URLを設定。
推奨サイズ1280×720、背景透明、表示は1件あたり約5秒です。
カードが横長なので、幅は1280以上あると見やすくなります。
背景パネルは透過済みです。カードと名前だけが表示されます。
枠付きに戻す場合はURLの末尾に ?panel=on を付けてください。
複数人が同時に押した場合は順番に表示されます。

【Firebase設定】
1. Firebaseプロジェクトを作成
2. Authenticationで匿名ログインを有効化
3. Firestore Databaseを作成
4. firebase-config.jsへウェブアプリ設定を貼る
5. firestore.rulesを公開
6. GitHub Pagesへ一式をアップロード
※v5では複合インデックスの作成は不要です。

【注意】
admin.html と stamp.html にはロックがありません。
URLを知っていれば誰でも開けます。配信画面にURLを映さないよう注意してください。
きちんと守りたい場合は、管理者だけメール＋パスワードのFirebase認証にして
firestore.rules で書き込みを制限する方法があります。
