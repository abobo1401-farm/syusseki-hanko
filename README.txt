りんごハンコ v6

【v5での修正】
■ 不具合の修正
・OBS通知：eventsが空の状態で開くと最初の1件が表示されなかった問題を修正
・OBS通知：同時に複数人が押したときの取りこぼしを修正（順番待ちで1件ずつ表示）
・リスナー画面：複合インデックス未作成でも動くようクエリを変更（active絞り込みをJS側へ）
・リスナー画面：エラー時に画面が無反応にならないよう、メッセージ欄に理由を表示
・ハンコボタン：連打による二重記録・二重通知を防止（押した瞬間に無効化）
・管理画面：出席の旬が「early / middle / late」と英語表示だったのを日本語に修正
・管理画面：出席を取り消すと対応するOBS通知履歴も一緒に削除
・公表ページ：改名後も古い名前が出ていた問題を修正（現在の登録名を表示）
・名前変更ボタン：検索欄と選択欄がリセットされるように修正

■ 仕様の変更
・日付の切り替えを23時に変更
  23:00～翌22:59が「1日」です。23時以降に押したハンコは翌日の出席になります。
  変更したい場合は common.js の DAY_ROLLOVER_HOUR を書き換えてください（0＝通常の日付）。
・ハンコの絵柄を1種類（りんごイラスト）に統一
  枚数による絵柄の変化（🍏／👑）は廃止しました。
  差し替えるときは assets/apple-stamp.png を同名で置き換えるだけです。
・カードの背景を手描きの木から、旬ごとのスタンプカード台紙イラストに変更
  上旬（1〜10日）・中旬（11〜20日）・下旬（21〜31日）で台紙が自動で切り替わります。
  ハンコは「押した日付のマス」に正確に入ります。順番でずれることはありません。

■ 追加
・管理画面に「通知履歴の整理」を追加（30日より前のeventsを一括削除）

【画像ファイル】
assets/apple-stamp.png   ハンコのりんごイラスト（384×384・背景透過）
assets/card-early.png    上旬の台紙（1〜10日／10マス）
assets/card-middle.png   中旬の台紙（11〜20日／10マス）
assets/card-late.png     下旬の台紙（21〜31日／11マス）

台紙イラストを描き直した場合は、common.js の CARD_CELLS にある
[中心X%, 中心Y%, マス幅%, マス高さ%] を新しいマス位置に合わせてください。

【画面】
index.html     入口
listener.html  リスナーが当日のハンコを押す
admin.html     PIN 1401で管理
obs.html       最新ハンコを約3秒表示
public.html    月別の出席回数を公表

【初回のリスナー操作】
1. 名前を検索またはプルダウンから選ぶ
2. 「この端末に名前を記憶する」
3. 「出席ハンコを押す」

【2回目以降】
URLを開き「出席ハンコを押す」だけです。
名前はlocalStorageに保存されます。
ブラウザのデータを削除した場合や、別端末では再登録が必要です。

【管理画面】
admin.htmlを開きPIN「1401」を入力します。
名前登録、修正、停止、削除、出席取り消し、LFR履歴管理、通知履歴の整理ができます。
※リスナー登録時は「よみがな」必須です。空だとリスナー画面の一覧に表示されません。

【OBS】
OBSブラウザソースにobs.htmlの公開URLを設定。
推奨サイズ1280×720、背景透明、表示は1件あたり約3秒です。
複数人が同時に押した場合は順番に表示されます。

【Firebase設定】
1. Firebaseプロジェクトを作成
2. Authenticationで匿名ログインを有効化
3. Firestore Databaseを作成
4. firebase-config.jsへウェブアプリ設定を貼る
5. firestore.rulesを公開
6. GitHub Pagesへ一式をアップロード
※v5では複合インデックスの作成は不要です。

【注意】
4桁PINはadmin.html内に保存される簡易方式です。
一般公開URLでは完全なセキュリティではありませんが、普段使いの誤操作防止には使えます。
